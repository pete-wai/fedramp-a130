Current Release Point

Public Law 119-118 (09/30/2026)

Each update of the United States Code is a release point. This page provides downloadable files for the current release point. All files are current through Public Law 119-118 (09/30/2026). Titles in bold have been changed since the last release point.

A User Guide and the USLM Schema and stylesheet are provided for the United States Code in XML. A stylesheet is provided for the XHTML. PCC files are text files containing GPO photocomposition codes (i.e., locators).

Information about the currency of United States Code titles is available on the Currency page. Files for prior release points and older materials are not yet available on this site.


All titles in the format selected compressed into a zip archive.
